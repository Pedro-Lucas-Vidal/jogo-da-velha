# Jogo da Velha Gamer (versão simples)

Projeto com HTML, CSS, JavaScript e Bootstrap 5. A aparência é clara e simples, como um site escolar, mas os jogadores continuam sendo **🎮 Controle** e **👾 Alien**.

## Como abrir

1. Extraia a pasta do arquivo ZIP.
2. Abra `index.html` no navegador (ou abra a pasta no VS Code).
3. Clique em uma casa para jogar e alterne os turnos com outra pessoa.

## Páginas
- `index.html`: jogo, placar e carrossel.
- `pages/historia.html`: resumo da origem do jogo da velha e versão com videogames. O botão **Saiba mais** abre essa página.
- `pages/dicas.html`: dicas simples de jogo.

O Bootstrap 5 é carregado por CDN, sem pasta `vendor/`. Para visualizar a formatação e o carrossel, é necessário estar conectado à internet. Para mudar o visual, edite `css/mystyle.css`. A lógica está em `js/myscript.js`.
